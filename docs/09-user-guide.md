## 1. 这是个什么东西

一个**跑在自己电脑上的网页**，用来检查、修改 RAG 切片：

- 左边一列：你的原件（Markdown 文档）；
- 中间一栏：原件原文，一行一行显示；
- 右边一栏：自动切好的「切片」（chunk，就是准备送进检索的小段文字）。

中间和右边是**联动的**：点原文里的某一行，右边会跳到对应的切片；点某个切片，原文会滚到它覆盖的那几行。你可以在这里拆分、合并、删除、改字、新增切片，最后**提交**，正式切片文件就会被更新。

它不联网、不上传任何东西，所有数据都在本机 `data/` 目录里。

## 3. 界面 30 秒看懂

从上到下、从左到右：

### 顶栏

| 位置 | 是什么 |
|---|---|
| 左边 | 产品名、版本（如 `P3`）、当前状态（如「已加载 XX · 185 块 · 对齐 185/185」） |
| 中间 | `↶ 撤销` `↷ 重做` |
| 偏右 | `保存草稿` `提交`（蓝色）`放弃` `导出` |
| 右侧 | 切块状态小标签（如「切块中 1/1 · 文件名」）、`⚙ 切块` `刷新` `⚙ 设置` |

### 左栏（文件）

- 最上面是搜索框：`搜索法规名 / 分组…`。
- 搜索框下面：`⬆ 添加文件` 按钮（也可以把文件直接拖进来，见第 4 节）。
- 文件列表按文件夹分组（现在一般只有一个 `data` 组），每个文件下面显示：
  - `切块 185`：这个文件有多少个切片；
  - `√`：切块质检通过；`⚠ N`：有 N 条警告（能打开，但建议看一眼）；
  - `本地`：来自本地两目录的数据源；
  - `草稿`：这个文件有未提交的草稿（见第 8 节）。

### 中栏（原文）

- 每行前面有行号。
- 最左边一列是**彩色范围条**：每种颜色代表一个切片覆盖的行范围；把鼠标放上去会显示是哪一块。
  - 如果一个超长块被自动拆成了多个「分片（part）」，会看到**两条**：外层浅色=整段范围，内层深蓝=当前分片自己的范围。
- 点原文某一行，会出现**蓝色光标**和上面的提示气泡（告诉你这一行属于哪个切片、能不能拆）。
- 表格会用真表格显示，可以直接选中行。

### 右栏（切片）

每张卡片左边有：

- `#序号`、类型（条款 / 表格 / 段落 …）、条号（如 `第二条`、`表A.3 第1-4行`）；
- 对齐状态：`精确` / `包含匹配` / `表格行匹配` / `表题定位` / `未对齐`（灰的）；
- `手工`：这一块被人工改过；
- 正文；
- 底部五个小按钮：`✂ 拆` `⤴ 并↑` `⤵ 并↓` `✕ 删` `✎ 改`。

## 4. 导入原件

原件必须是 Markdown（`.md`）。两个办法：

**办法一：点按钮**

1. 点左栏的 `⬆ 添加文件`；
2. 在弹出的文件选择框里选一个或多个 `.md` 文件（也接受 `.markdown`、`.txt`，会按 `.md` 存）；
3. 等右下角提示「已导入 N 个…」。

**办法二：拖进来**

直接把文件从资源管理器拖到**左栏任意位置**，左栏出现蓝色虚线框和「松开导入到 data/source」时松手即可。

规则（简单记：UTF-8、别重名、别太大）：

- 文件必须是 **UTF-8 编码**的文本，不是的话会提示「不是 UTF-8 编码（请先转码）」；
- 同名文件**不会覆盖**，会跳过并在提示里告诉你；
- 单个文件 ≤ 16MB，一次最多拖 64MB；
- 导入成功后会自动触发切块（见下一节）。

## 5. 自动切块

导入的新文件会被自动切块引擎（SPLITCHUNK）处理：

1. 你导入后，顶栏出现小标签「**切块中 1/1 · 文件名**」，说明正在切；
2. 几秒后变成「**已切块 1 份**」，左栏自动出现这个文件（带 `√` 或 `⚠`）；
3. 点文件就能看了。

**手动切块**：如果没自动触发，点顶栏 `⚙ 切块`，它会扫描 `data/source` 里所有「还没有切块」的文件。

**失败了怎么办**：文件行会出现 `⚠`，卡片数量可能为 0。常见原因是原件不是 UTF-8；用记事本另存为 UTF-8 后重新导入。

**改了原件会怎样（重要，务必看）**

只要「自动切块」开着（默认就是开的），工具每 3 秒扫一次 `data/source`。一旦发现某个原件**内容变了**（和上次切块时的 sha 对不上），它会**自动重新切块**，用新结果覆盖 `data/chunks/<文件名>/`。后果是：

- 这个文件**未提交的草稿会变成「草稿已过期」**，之前的修改没法再提交；
- 重新切块会重新编号（id 会变），之前的手工修改不会保留。

所以：**改原件之前，先把这个文件里未提交的修改点「提交」**（或者确认这些修改不要了）。

不想被自动覆盖：`⚙ 设置` → 取消勾选「自动切块」→ 以后改完原件自己点 `⚙ 切块`。

想强制重切某个文件（比如切块器升级后）：先提交/放弃草稿 → 设置里关掉自动切块 → 删掉 `data\chunks\<文件名>\` 文件夹 → 点 `⚙ 切块`（或重新打开自动切块并刷新）。

## 6. 看：原文和切片怎么对上

1. 左栏点一个文件；
2. 中栏出现原文，右栏出现所有切片卡片；
3. 鼠标放到原文某行 → 右边对应卡片高亮；放到右边卡片 → 原文对应行高亮；
4. 点原文某行 → 右栏自动选中并滚到覆盖这一行的切片；
5. 点右边卡片 → 原文自动滚到它覆盖的那几行（相当于 `◎ 定位到切片`）。

**对齐状态怎么看**：

- `精确` / `包含匹配` / `表格行匹配` / `表题定位` = 找到了它在原文的位置；
- `未对齐`（灰色）= 没找到，可能是原件改过或切块器合并过。依然可以编辑，不影响使用。

**表格**：原文里的表格会渲染成真正的表格；右边卡片里的表格也会显示成表格（带表头）。两边都可以悬停、点击联动。

## 7. 改：怎么调整切片

所有修改都只改「内存里的工作副本」，先不会动正式文件（见第 8 节保存）。

### 7.1 选中

- 点卡片 = 选中；
- 点原文某行 = 选中覆盖该行的切片；
- 按下 `Ctrl` 再点卡片 = 多选（再按 `Delete` 可一次删掉多块）。

### 7.2 拆分（一块变两块）

方法任选：

- 卡片上点 `✂ 拆`，在弹层里确认（可改下半块的条号）→ `确认拆分`；
- 原文里点一下目标位置（出现蓝色光标）→ 右键 → `✂ 在光标处拆分`；
- 快捷键 `Ctrl+Enter`（对当前选中的卡片拆分）。

### 7.3 合并（多块变一块）

- 卡片底部：`⤴ 并↑`（和上一块合并）、`⤵ 并↓`（和下一块合并）；
- 原文里拖选跨过多块 → 右键 → `⤵ 合并所选 N 个切片`（要求这些块在原文里是连续的）；
- 合并后被并掉的块消失，保留第一块的编号；`Ctrl+Z` 可撤销。

### 7.4 删除

- 卡片上 `✕ 删`，或选中后按 `Delete`；
- 多选多张卡片后按一次 `Delete` = 一次删除全部（一次 `Ctrl+Z` 撤销）；
- 原文拖选一段 → 右键 → `✕ 删除所选 N 个切片`；
- **删除分片（part）时会问你**：「只删这一片 / 删除整组 / 取消」。如果这一块是超长块自动拆出来的，一般选「删除整组」。

### 7.5 改正文 / 条号 / 类型

卡片上 `✎ 改` → 改正文、`law_num`（条号）、类型（条款/表格/段落…）→ `保存修改`。

### 7.6 新增

- 右栏 `＋ 新增`：手动输入正文、条号、类型 → `新增`；
- 原文里拖选一段文字 → 右键 → `✚ 用选区新增切片`，正文会自动带入；
- 表格里拖选行 → 右键 → `✚ 用选中的表格行新增切片`，正文按「列名：值」自动拼好，条号会按相邻切片自动预填。

### 7.7 扩展（把后面一段并入当前块）

从某个切片的**第一行行首**开始拖选，一直拖过这个切片的末尾，继续选到后面的内容，然后点 `＋ 新增` 或右键选新增：弹层会变成「**⤢ 扩展切片**」，提交后是在原切片上**扩展**（不会新建一块），行区间自动变长。

### 7.8 并入缺口（把没有切片的一段并进下面的块）

从一段**没有切片**的文字（标题、目录、空行、缺口）开始拖选，一直选进下面某个切片内部 → 右键菜单的**第一项**就是「**⤢ 把未切片选区并入 #N 切片**」。提交后这段原文会并入该切片前面，块数不变、行区间前移。

### 7.9 撤销 / 重做

- `Ctrl+Z`：撤销上一步；
- `Ctrl+Y` 或 `Ctrl+Shift+Z`：重做。

### 7.10 表格里怎么操作

- 在表格里按住左键拖过哪几行就选中哪几行（琥珀色底）；
- `Shift`+点击：从上次位置扩展选择；
- 单击已有切片的表格行 = 选中那个切片（不是选行）；
- 拖到表格容器上/下边缘会自动滚动继续选；
- 右键：
  - 全是没切片的行 → `✚ 用选中的表格行新增切片`；
  - 选区包含切片 → `⤵ 合并所选 N 个切片` / `✕ 删除所选 N 个切片`。

> 按 `Esc` 或点表格外面可以取消行选择。

## 8. 存：草稿、提交、放弃、导出

改的过程是这样保护你的：

### 草稿（自动）

- 你每改一下，**2 秒后自动存草稿**到 `data/draft/`；
- 顶栏中间会显示草稿状态：
  - `● 有未保存修改`：刚改完，还没自动存；
  - `草稿已保存未提交`：草稿存好了，但正式文件还没变；
  - `⚠ 草稿已过期`：正式文件被别的东西改过，这份草稿不能再提交了；
- 左栏文件行也会显示 `草稿`；
- 切到别的文件、刷新页面、甚至重启服务，草稿都还在，重新打开该文件会自动恢复。

### 提交（正式生效）

点顶栏 `提交`：

1. 先检查基线（确认正式文件没被别处改过）；
2. 把旧版本备份到 `data/backup/`（自动保留最近 3 份）；
3. 用你的修改**覆盖**正式切片文件；
4. 删掉草稿，状态变成干净。

**提交之后才算真正保存**。关了服务再打开，看到的就是提交后的结果。

### 放弃

点 `放弃` = 扔掉这份草稿，回到自动切块的原始结果。会再问一次，确认才执行。

### 导出

点 `导出` = 下载当前切片（包括没提交的修改）的 `.jsonl` 文件，用于交给别的程序。

> 一句人话：**草稿 = 草稿纸；提交 = 誊写到正式本子上；放弃 = 撕掉草稿纸；导出 = 复印一份带走。**

## 8.5 设置里那几个开关（⚙ 设置）

一般不用动，知道有这几个就行：

| 设置项 | 什么意思 | 建议 |
|---|---|---|
| 本地数据目录 `data_root` | 原件和切片放在哪 | 默认 `data`，别乱改 |
| 端口 `port` | 网页用哪个端口（默认 8790） | 打不开且提示端口占用时才改，改完重启 |
| 自动分 part `auto_part` | 超长块在加载时自动拆成 `-p1/-p2…` 分片 | 默认**关**；需要拆超长块时再开 |
| 自动拆分阈值 `max_chars` | 超过多少字才拆（默认 800） | 开 auto_part 后生效 |
| 最小 part 长度 `min_part_chars` | 尾巴太短会并入上一片（默认 200） | 同上 |
| 自动切块 `auto_chunk` | 发现新原件/原件改了自动调用引擎切块 | 默认**开**；怕覆盖手工结果可关掉 |
| 切块引擎目录 `chunker_root` | SPLITCHUNK 引擎在哪 | 留空自动探测（`vendor/splitchunk`） |
| 轮询间隔 `chunker_poll` | 几秒扫一次新文件（默认 3） | 一般不用改 |

改完点 `保存` 立即生效（端口要重启服务）。

## 8.6 给文件标「来源类别」（推荐做一次）

左边每个文件可以标一个类别，检索时按「类别 + 文件名」过滤更准：

1. 在左栏**右键**任意文件 → 点「🏷 来源类别…」；
2. 点选择框右侧的 `▾` 展开列表，选一个：`法律` / `部门规章` / `地方标准` / `规范性文件`（也可以选「未设置」清掉）；
3. 列表里没有合适的？点最下方「＋ 新增自定义来源」→ 输入名称（如「行政法规」）→「确定添加」，新类别会出现在列表里并被自动选中；
4. 选完这条文件下**所有切片**的 `source` 都会改成该类别，文件行出现紫色类别徽章；有草稿会一起同步；
5. 标来源**不会改变审核状态**：已审核的文件标完仍是绿的，审核中的仍是黄的，未审核的仍是红的；重新打开也不会变回未审核。

重新切块不会丢掉这个标注（记在 `data/sources.json`）。

## 9. 出问题了怎么办

**页面打不开 / 白屏 / 报错**

- 先按 `Ctrl+F5` **强制刷新**（很多问题是浏览器缓存了旧脚本）；
- 看黑色命令行窗口最后几行有没有红字，把红字发给我；
- 确认地址是 `http://127.0.0.1:8790/`，端口被占用时可在 `⚙ 设置` 里换端口。

**页面中文变成乱码**

- `Ctrl+F5` 强刷；还乱说明静态文件被写坏了，用 `git status` 看 `web/` 下文件是否被改，必要时 `git checkout -- web/` 恢复。

**左栏没有我刚放进去的文件**

- 点顶栏 `刷新`（重新扫描 `data/source` 与 `data/chunks`）；
- 确认文件名配对：`data/source/<名>.md` 对应 `data/chunks/<名>/`；
- 刚导入的还没切完，等顶部小标签显示「已切块」后会出现。

**一直显示「切块中」不动**

- 看命令行窗口有没有引擎报错；
- 原件不是 UTF-8 时切块会失败，转成 UTF-8 再导入；
- 点 `⚙ 设置` 看「切块引擎路径」是否自动填上了。

**提示「草稿已过期」**

- 说明正式切片文件在别处被改过（比如重新切块、别人提交）。只能 `放弃` 草稿，重新编辑。

**删了分片想恢复整组**

- 删除时选「删除整组」；
- 已经删了：`Ctrl+Z` 撤销，或从 `data/backup/` 里把上一版复制回去再 `刷新`。

**表格里的图片看不到**

- 工具会把图片位置显示为 `[图示]`，这是正常的（切片文本里不带图）。

**误操作**

- 一律先 `Ctrl+Z`；
- 已经提交了：去 `data/backup/<文件名>.<时间戳>.jsonl` 找回上一版，复制到 `data/chunks/<文件名>/<文件名>.chunks.jsonl`，点 `刷新`。

**想确认自己有没有改成功**

- 提交后左栏看块数、右栏看卡片、原文看范围条；也可以点 `导出` 打开 jsonl 对一眼。

## 11. 数据存在哪

所有东西都在 `data/` 下（这个目录不进 git，不会误提交）：

```
data/
├─ source/                     原件
│   └─ 中华人民共和国消防法.md
├─ chunks/                     切块产物（每份文档一个文件夹）
│   └─ 中华人民共和国消防法/
│       ├─ 中华人民共和国消防法.chunks.jsonl    ← 正式切片（提交后更新）

    └─ 中华人民共和国消防法.20261105-111654.jsonl
