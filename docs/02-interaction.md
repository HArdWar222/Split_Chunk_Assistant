# 02 · 交互设计

> 界面目标：打开任意一份法规 Markdown，10 秒内看懂「切成了哪些块、每块落在原文哪里」，
> 并能在不改变自动流程的前提下，手工修正切块边界与少量元数据。

---

## 2. 三栏内容

### 左栏：文件树

- 按 `group`（national_laws / GB_laws）分组折叠；
- 每个文件一行：`块数` + 编辑徽章（已改 N / 有 miss 黄点）+ 对齐分布小徽章；
- 顶部搜索框（按文件名 / 法规号模糊匹配），支持 `↑↓` 键盘选择、`Enter` 打开；
- 每 97 个文件不需要分页（一次全量返回）。

### 中栏：原文视图

- **Markdown 源码行模式**（默认且唯一模式，P5 可选渲染视图）：
  - 行号 gutter（真实源行号，展开行显示 `112+1`）；
  - 轻量格式化：`#` 标题加粗、`**` 粗体、列表符着色、`|` 表格行合并显示、代码块等宽；
  - 超长单行（HTML 大表）折叠成 `[HTML 表格 312 行，点击展开]`，展开后按 `source_line_map` 显示为虚拟行；
- **节导航**：右上角浮层列出全部 `##` 级标题，点击跳转；
- **切片高亮**：每个块对应行区间着色（相邻块换色相、overlap 部分斜纹），当前选中块描边；
- **对齐标识**：`miss` 的块对应行区间标灰虚线（不伪造高亮）；`approx` 标黄色虚线；
- 行内拆分点用竖线光标、拆分预览（上下两块编号）实时显示。

### 右栏：切片卡片

每张卡片：

- 头部：`id`（等宽小字）+ `chunk_kind` 标签 + `token_len` + `part_index/part_total`；
- 正文：前 6 行预览（点击展开全文，可编辑态 textarea）；
- 元数据行：`law_num`、`law_type`、`law_level`（可点开编辑面板）；
- 对齐状态点：`● exact` / `◐ table_rows` / `○ approx` / `✕ miss`；
- 操作按钮：`拆`（在光标处/行边界拆）、`并↑`、`并↓`、`删`、`定位`（滚动原文到块）；
- 底部小字：extras 摘要（表格块显示 `表A.1 · 3 行`，probe 显示 `family/confidence`）。

## 3. 交互清单

| 交互 | 触发 | 行为 |
|---|---|---|
| 双向定位 | hover 卡片 / hover 原文块 | 另一端加描边 class 并滚到可见区（仅滚动一次，300ms 内不重复触发） |
| 锁定 | 单击卡片或原文块 | 高亮变实线并固定在视口；再次单击其他区块切换锁定；`Esc` 取消 |
| 点原文行反查 | 单击某行 | 右栏滚动到包含该行的第一张卡并选中 |
| 原文拖选反查（P1 已实现） | 在原文里拖选一段文字 | 高亮覆盖该行范围的全部切片卡片（`.hit`），状态栏显示「原文第 a–b 行 → 对应 N 个切片」；选区中包含未对齐行时如实提示「没有对应的切片」；取消选区即清除 |
| 范围条观察（P1 已实现） | 原文行左侧 20px 泳道 | 每个已对齐切片的行区间画成彩色竖条（`start/end` 处留缺口显示边界，4 条泳道承载重叠块）；悬停 tooltip 显示「切片 #n · id · 第 a–b 行」或「该行被 N 个切片覆盖」；点击竖条选中对应卡片；原文面板右上角「范围条」复选框可开关，偏好存 localStorage |
| 拆（行边界） | 卡片 `拆` 或 gutter 手柄 | 以当前光标行切成两块，自动重算 id/part/hash |
| 拆（行内） | 双击原文行内字符位置 | 生成 inline span 切点，按字符拆成两块 |
| 调边界（拖拽） | 拖块首/尾行号手柄 | 实时预览上下块文本，松开生效；跨块拖动时提示是否吸收 |
| 合并 | `并↑` / `并↓` | 与前/后块合并，part 规范化为一块 |
| 集体合并 | 在原文拖选覆盖 2 个以上切片 → 右键 | 菜单出现「⤵ 合并所选 N 个切片」，一次把选中的连续多块合并成一块（保留第一块 id/条号/kind，行区间取并集，diff 显示 `-N`） |
| 删除 | `删` | 块从结果移除，源文不动；可撤销 |
| 新增（P2 已实现） | 原文上拖选若干行 → 工具栏「＋新增」或 `Ctrl+Shift+N` | 弹层自动带入选区文本并记录行区间 `span`；提交后新块插到覆盖该选区的最后一个切片之后：正文 = 选区文本、`manual`、`span = [起始行, 结束行]`，原文范围条与卡片底部行区间同步出现；不选区时保留手动输入正文新增（`span = None`）；**id 按原文位置重排**（新块 = 列表序号，插入点之后的块顺延；同组 part 共用 base 序号） |
| 右键工作栏（P2 已实现） | 在原文拖选后（或直接在切片行上）右键 | 弹出上下文菜单：`✂ 在此处拆分（光标处）`（当右键位置落在某个切片内部时，首项；按光标在块内第几行自动选行级/字符级拆分）/ `✚ 用选区新增切片`（带选区行区间与字数提示）/ `✂ 拆分此切片…` / `✎ 编辑此切片正文·条号…`（点开即带入该块正文、条号、kind，改完保存两栏立即刷新）/ `⤴ 并入上一块` / `⤵ 并入下一块` / `⤵ 合并所选 N 个切片`（拖选覆盖 ≥2 个切片时）/ `✕ 删除此切片` / `◎ 定位到切片`；「并入上一块/下一块」两个方向都支持（合并后保留前一块 id）；无选区时只显示切片操作；首尾块的「并入」自动禁用；**右键落在没有切片覆盖的行（标题/目录/空行/未对齐区域）时菜单依然弹出**，显示 `ℹ 第 N 行不属于任何切片` 与 `✚ 用这一行新增切片`（该行原文带入新增弹层；顶部缺口新增会插到列表最前，保持原文顺序）；点空白/滚动/`Esc` 收起；任一操作提交后右栏卡片与原文范围条立即重新渲染 |
| 改正文 | 卡片双击正文 | 进入编辑态 textarea；失焦保存草稿；标 `manual`，span 置灰 |
| 改元数据 | 卡片 `law_num / chunk_kind / part_*` 点击 | 内联编辑；非法值即时红框提示 |
| 参数重切 | 顶栏参数面板改动 → `重切` | 弹层展示新旧对比（新增/删除/修改块），确认后替换当前视图（不自动保存） |
| 保存 | `Ctrl+S` / 顶栏 `保存` | 校验全部块 → 写覆盖层 → 顶部提示 `已保存 HH:MM:SS` |
| 重置 | 顶栏 `重置` | 二次确认后删除覆盖层，回到基线 |
| 导出 | 顶栏 `导出` | 下载当前文档的 15 字段 JSONL（文件名 `<law_name>.jsonl`） |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Shift+Z` | 会话内命令栈；保存不中断栈 |
| 搜索块 | 顶栏搜索框（右栏聚焦时） | 按正文/law_num/id 过滤卡片并高亮 |
| 跳块 | `↑↓`（卡片聚焦） | 在卡间移动并滚动原文 |

## 4. 状态与反馈

- **dirty**：任一块被修改后，顶栏显示 `● 未保存`，导出/关闭时二次确认；
- **diff 计数**：`+新增 ~修改 -删除` 相对基线实时计算；
- **对齐徽章**：文件树与状态栏展示 `exact / table_rows / approx / miss` 数量；
- **stale**：源 md 的 sha256 与覆盖层 meta 不一致时，顶栏黄条：`源文件已变更，建议重切或重置`；
- **错误**：保存失败（契约校验不过）弹出具体字段与块 id，不写盘；网络错误重试按钮；
- **空态**：左栏无文件 → 提示检查 `data_root`（下需含 `source/` 与 `chunks/`）。

## 6. 性能策略

| 场景 | 策略 |
|---|---|
| 1200+ 行文档 | 中栏行虚拟化（视口 ±50 行），只挂可见 DOM |
| 836 块文件 | 右栏卡片虚拟列表（约 30 张可见） |
| hover 高亮 | 只切 class，不重建子树；requestAnimationFrame 合并滚动 |
| 首屏 | `/api/files` 轻量元数据；`/api/doc` 按需加载；文档 LRU 缓存 4 份 |
| 大响应 | 响应体 `Content-Encoding: gzip`（stdlib 手写实现） |
| 对齐计算 | 每文档一次，结果按 `source_sha256` 落 `cache/align/` |
