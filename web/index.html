✂ 拆分切片

选择在哪一行之前切开：上半块保留原 id 与原条号，下半块获得新 id（max_seq+1）。 单行块按字符位置拆。拆完若下半块条号不同，可在下面直接填，或之后用「改」逐个改。

✎ 编辑切片

改正文会重算 token_len / chunk_hash 并标记 manual，与原文区间脱钩。

＋ 新增切片

在原文里拖选一段文字后点「新增」，选区会直接变成切片并记录行区间；未选区时手动输入正文，插入到当前选中切片之后（未选中则追加末尾），id = 当前最大 seq+1。
